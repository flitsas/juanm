# reglas-frontend

## ADDED Requirements

### Requirement: Rule builder UI

The frontend SHALL provide a visual rule constructor with field picker, operators, AND/OR grouping, template binding, and activation toggle.

### Requirement: Scheduler and results UI

The frontend SHALL display execution schedule configuration, manual run trigger, and per-run match listings.

### Requirement: Logs and contacts UI

The frontend SHALL expose execution logs, processing metrics, and secretariat contact management with Flit Ready tokens and four UI states (empty, loading, error, full).
