# reglas-secretariat-access

## ADDED Requirements

### Requirement: Secretariat contact directory

The system SHALL allow CRUD of contacts keyed by secretariat identifier with email and dispatch metadata.

### Requirement: Recipient resolution

When dispatching, the system SHALL resolve the recipient from the comparendo's secretariat using the configured contact directory.

### Requirement: Role-based access control

The system SHALL restrict create/edit rules, manual execution, and log viewing according to tenant role policies.
